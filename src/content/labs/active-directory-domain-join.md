## Overview

This lab focused on connecting a Windows client workstation to an Active Directory domain in a virtual lab environment.

## Objective

The objective was to configure domain communication correctly and successfully join a Windows client to the domain.

## Key Tasks

- Configure network connectivity
- Configure DNS
- Verify domain controller communication
- Join the Windows client to the domain
- Authenticate using domain credentials
- Validate Group Policy communication
