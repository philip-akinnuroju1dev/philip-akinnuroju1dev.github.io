My objective is to develop practical programming and statistical computing skills that can be applied across data analytics, cybersecurity and research.

- Statistical analysis
- Automation
- Machine learning
- Security-focused programming

## R

My R learning will progress from the fundamentals of the language into:

- Data manipulation
- Statistical computing
- Data visualisation

- Research applications

Rather than focusing only on tutorials, I intend to combine theoretical learning with exercises and practical projects.

Important exercises and experiments will be documented through this journal, while larger completed projects will be presented separately in my portfolio.

The long-term goal is to develop strong practical skills in Python and R for use across data analysis, cybersecurity analytics, machine learning and technical research.
